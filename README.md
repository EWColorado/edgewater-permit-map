# Edgewater active permit map

A map of active City of Edgewater permits, built from CommunityCore data and placed using
Jefferson County's address layer. Fee amounts are not shown; a black ring marks permits with
a balance due. The data is updated by hand, so check the date in the map.

Live map: https://ewcolorado.github.io/edgewater-permit-map/

Created by Kit Lammers, City of Edgewater, with AI, 2026.
